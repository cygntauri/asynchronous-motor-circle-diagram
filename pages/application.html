Guide to Using the Asynchronous Machine Circle Diagram Application

This section provides a comprehensive and structured explanation of how to use the induction machine analysis tool from start to finish. It guides the user through entering accurate experimental test data, launching the calculation process, and understanding how the system processes these inputs.

It also clarifies how the generated circle diagram reflects the machine’s operating behavior and how key parameters such as slip, efficiency, power factor, and power distribution are derived. By following these steps carefully, users can ensure reliable results and gain deeper insight into the machine’s performance under different operating conditions.

Comprehensive Input, Visualization, and Performance Analysis of the Asynchronous Machine

This section brings together all the essential stages required for a complete and rigorous analysis of the asynchronous induction machine. It starts with the entry of nameplate data and experimental test results, including no-load, blocked-rotor, and stator resistance measurements, which form the foundation of the electrical model.

Once the data is entered, the tool generates the circle diagram and a set of characteristic curves that illustrate the machine’s behavior over a wide operating range. Interactive visual elements such as zoomable diagrams and performance gauges help the user intuitively identify the operating point in terms of current, power, torque, and speed.

Finally, detailed numerical results are presented through power balance tables and electrical, mechanical, and electromagnetic parameters, allowing a clear understanding of losses, efficiency, slip, and overall machine performance.

Performance Characteristics and Operating Curves

This section presents the main performance characteristics of the asynchronous machine through a set of graphical curves.
These plots illustrate the relationships between torque, speed, slip, current, power factor, and efficiency. By analyzing these curves, it becomes possible to better understand the machine’s behavior under different operating conditions, identify characteristic operating points, and evaluate key performance indicators such as efficiency, power factor, and current consumption.

Point Determination with Load Torque

This section allows the user to define a load torque law as a function of the rotational speed N. The entered expression is validated to accept only numerical values, the variable N, and the + or − operators.
The load torque curve is then plotted on the same graph as the machine useful torque characteristic.
The operating point is automatically determined as the intersection of the two curves. The corresponding slip is calculated from the intersection speed and the synchronous speed, and the resulting operating point is finally plotted on the circle diagram.

Motor Operating Dashboard

The dashboard provides a real-time visualization of the asynchronous machine operating point using circular gauges. Each indicator represents a normalized quantity—current, power, torque, and speed—expressed with respect to its rated value.
This visual approach makes it easier to assess the machine loading level, compare operating conditions, and quickly identify deviations from nominal or critical states.

Computed Results and Machine Parameters

The results area summarizes the complete electrical and mechanical behavior of the asynchronous machine at the selected operating point. It presents the detailed power balance, including stator, rotor, iron, and mechanical losses, as well as the resulting useful power and efficiency.

In addition, the equivalent electrical parameters, mechanical quantities, and supply-related values are displayed to provide a comprehensive and structured overview of the machine’s operating conditions.
